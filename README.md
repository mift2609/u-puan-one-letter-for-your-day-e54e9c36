One letter. One day. No words wasted — because after a night shift, there are no words left.

## The letter

**Z** — for **zero sleep**. A night-shift day: eyes half open, brain on standby, body running on instant coffee and stubbornness.

## How it works

`main.py` (Python 3, stdlib only) writes the single letter to `/output/entry.txt`, then re-reads the file and asserts it contains exactly that one capital letter, A–Z.

```sh
python3 main.py
```
